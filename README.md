# پایگاه مقالات و منابع پایان‌نامه MBA

این پروژه یک وب‌اپلیکیشن ساده برای **سازماندهی و مدیریت لینک مقالات و منابع مورد استفاده در پایان‌نامه MBA** است. لینک‌های مقالات از یک فایل دریافت و در یک محیط مرتب نمایش داده می‌شوند تا بتوان به‌راحتی منابع را مشاهده، جستجو، فیلتر و باز کرد و در صورت نیاز لینک هر مقاله را کپی کرد. همچنین تعداد منابع و صفحات نمایش داده می‌شود و با قابلیت بروزرسانی، لیست مقالات دوباره بارگذاری می‌شود. هدف اصلی این پروژه این است که منابع پایان‌نامه به‌جای پراکنده بودن، در یک محیط ساده و منظم در دسترس باشند و پیدا کردن و مدیریت آن‌ها راحت‌تر شود.
